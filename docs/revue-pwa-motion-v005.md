Fab : « On ne peut pas l’activer par défaut ? ». Le réglage motion est déjà ON par défaut ; build4 imposait le bouton Réglages lorsque le navigateur expose requestPermission.

Les clics synthétiques sont ignorés. BrowserMotion.activateOnInteraction ne demande qu’en état permission ; request borne les demandes concurrentes, y compris bouton manuel + remontée du clic dans document. Après un refus, aucune répétition automatique dans le document ; le bouton manuel permet un nouvel essai. Les autorisations du navigateur continuent de s’appliquer. Une permission accordée ne prouve pas la présence de données : disponibilité après mesures valides seulement.
