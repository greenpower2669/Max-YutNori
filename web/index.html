Quatre bâtonnets, mille chemins.

Faites arriver vos quatre pions avant les autres équipes. Lancez les bâtonnets, choisissez un résultat, puis un pion et sa destination.

Do · 1 / Gae · 2 / Geol · 3
Avancez de 1, 2 ou 3 cases.
Yut · 4 / Mo · 5
Le résultat est conservé et vous relancez. Jouez ensuite vos résultats dans l’ordre voulu.
Back-do · −1
Seul le bâton marqué montre sa face plate : reculez d’une case. Depuis la réserve, reculez vers la case 19 ou le raccourci près de l’arrivée : le pion doit alors accomplir un tour supplémentaire.

Un pion adverse sur votre case repart à la réserve. Vos pions réunis voyagent ensemble. Les raccourcis se choisissent en quittant les coins 5 et 10 ; au centre, choisissez votre sortie. Chaque franchissement avant de la ligne 20 retire un tour ; partir en arrière depuis la ligne en ajoute un. Le pion termine quand il ne lui reste aucun tour. Une capture réinitialise son parcours.

Touchez un pion, même dans la réserve, ou faites-le glisser vers une destination lumineuse. Le halo s’agrandit lorsque le dépôt est possible. Un deuxième doigt règle le zoom pendant la prise. La caméra action s’approche, se décale et recule pour suivre le pion ; « Plateau » rétablit la vue générale.

Dans la vue « Bol et lancer », posez le doigt sur le bac : glissez vers le haut pour le soulever, vers le côté pour l’incliner. Relâchez pour le reposer. Pour lancer, utilisez le bouton ou glissez sur la table en dehors du bac. Le bac se manipule avant un lancer humain. Les bâtonnets peuvent retomber dans le bac ou sur la table à rebords. Les boutons restent disponibles. Noir laqué : face plate ; cèdre rouge : face bombée. L’étoile repère le bâton Back-do. Si un bâton reste coincé sur la tranche, relancez.

La capture ne donne pas de relance par défaut. Cette variante se règle avant une nouvelle partie.
