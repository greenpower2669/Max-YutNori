Back-do · −1
Seul le bâton marqué montre sa face plate : reculez d’une case. Depuis la réserve, reculez vers la case 19 ou le raccourci près de l’arrivée : le pion doit alors accomplir un tour supplémentaire.

Un pion adverse sur votre case repart à la réserve. Vos pions réunis voyagent ensemble. Les raccourcis se choisissent en quittant les coins 5 et 10 ; au centre, choisissez votre sortie. Chaque franchissement avant de la ligne 20 retire un tour ; partir en arrière depuis la ligne en ajoute un. Le pion termine quand il ne lui reste aucun tour. Une capture réinitialise son parcours.

Touchez un pion, même dans la réserve, ou faites-le glisser vers une destination lumineuse. Le halo s’agrandit lorsque le dépôt est possible. Un deuxième doigt règle le zoom pendant la prise. La caméra action s’approche, se décale et recule pour suivre le pion ; « Plateau » rétablit la vue générale. Le bouton ×2 rapproche réellement la caméra puis la ramène au cadrage normal, sans cumul ; votre pincement reste indépendant. Le cadrage automatique garde le plateau entier visible avec le pion et ses destinations ; le rapprochement ×2 s’arrête à cette limite. Votre pincement reste libre. « Vue de dessus » garde le plateau vertical sous votre regard : pincez avec deux doigts pour zoomer ou dézoomer, même sans tenir de pion.

Dans la vue « Bol et lancer », posez le doigt sur le bac : glissez vers le haut pour le soulever, vers le côté pour l’incliner. Relâchez pour le reposer. Pour lancer, utilisez le bouton ou glissez sur la table en dehors du bac. Le bac se manipule avant un lancer humain. Dès que les quatre yut ont entièrement franchi son rebord, il s’efface avec son socle ; en fin de tour ou avant une relance, il revient ranger les quatre yut. Attendez la fin du rangement pour lancer. Les pions de l’équipe qui joue portent un anneau à lumière pulsée. Le pion choisi se soulève ; le mode « Réduire les animations » garde une lumière fixe. Les bâtonnets retombent sur la table, retenus par des limites invisibles en hauteur. Les boutons restent disponibles. Noir laqué : face plate ; cèdre rouge : face bombée. L’étoile repère le bâton Back-do. Si un bâton reste coincé sur la tranche, relancez.

La capture ne donne pas de relance par défaut. Cette variante se règle avant une nouvelle partie.
